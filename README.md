# Life Soundtrack 🎧

A dashboard of theme music for everyday life, synthesized live in the browser with the Web Audio API (no audio files).

- **Mission: Possible** — tense 5/4 spy theme (inspired by *Mission: Impossible*)
- **Assemble** — heroic brass anthem (inspired by *The Avengers*)

Features: visualizer, seek, tempo and volume controls, loop, per-part mixer, keyboard shortcuts.

Open `index.html` locally, or visit the GitHub Pages deployment.
